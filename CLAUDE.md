# Bnnr Studio – werkafspraken

- Communiceer in het Nederlands.
- Eindig elk antwoord aan de gebruiker met hoe de app te openen/bijwerken op de Mac:
  `cd ~/banner-studio`, `git pull`, `npm install`, `npm run dev`
  (bij "Electron failed to install correctly": `node node_modules/electron/install.js`).
- Werk op branch `claude/banner-studio`; draai `npx tsc --noEmit`, `npx vitest run` en de rooktests in `scripts/` vóór het pushen.
